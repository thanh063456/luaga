# 🧩 Chrome Extension: FB Job Poster Assistant

Extension hỗ trợ tự động điền tin tuyển dụng 1-Click vào Facebook Group trực tiếp từ ứng dụng web **FB Job Poster**.

## 🚀 Hướng dẫn cài đặt nhanh (Mất 10 giây):

1. Mở trình duyệt Chrome hoặc Edge, truy cập:
   * Chrome: `chrome://extensions/`
   * Edge: `edge://extensions/`
2. Bật công tắc **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
3. Bấm nút **Tải tiện ích đã giải nén (Load unpacked)**.
4. Chọn thư mục: `D:\Lùa Gà\fb-job-poster\extension`.
5. Ghim (Pin) biểu tượng 📣 **FB Poster Assistant** lên thanh tiện ích trình duyệt.

## 🎯 Cách sử dụng:
1. Mở ứng dụng web FB Job Poster tại `http://localhost:3000` (đảm bảo đang chạy `npm run dev`).
2. Mở Facebook và vào bất kỳ Group nào bạn muốn đăng bài.
3. Bấm vào icon tiện ích ở góc trình duyệt -> Bấm **⚡ Điền 1-Click**.
4. Nội dung bài viết sẽ được tự động điền vào khung tạo bài viết của Facebook kèm thông báo thành công!
